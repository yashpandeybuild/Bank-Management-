# 🏦 Atom Bank — Bank Management Demo

A simple bank management web application built using Python and Streamlit as part of my learning journey.

## 🚀 About the Project

For the past few days, I was wondering how Python is used in real-world applications. While learning Python, I wanted to see how it works in a practical project.

So, I explored how to create a basic banking website using **Python and Streamlit**.

This project helped me understand how Python code can be used to create a web application with a simple user interface.

## ✨ Features

- 💰 Deposit money
- 💸 Withdraw money
- 🏦 Check account balance
- 🖥️ Interactive web interface using Streamlit
- 🎨 Dark mode and light mode
- 🧹 Clean and organized code

## 🛠️ Technologies Used

- **Python** — Main programming language
- **Streamlit** — To build the web application
- **JSON** — To store data, where implemented in the project

## ▶️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/yashpnd4/-bank-management-modified-.git
   ```

2. Open the project folder:

   ```bash
   cd -bank-management-modified-
   ```

3. Install Streamlit:

   ```bash
   pip install streamlit
   ```

4. Run the application:

   ```bash
   streamlit run app.py
   ```

   Replace `app.py` with the actual Python filename if it is different.

## 📌 Important Note

This is a **learning and demonstration project**, not a real banking application. It is not intended for handling real money or sensitive financial information.
