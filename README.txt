ATOM BANK — STUDENT STREAMLIT PROJECT

Files:
- app.py: main Python application
- requirements.txt: required library

Run it:
1. Open this folder in VS Code.
2. In the terminal, run: python -m pip install -r requirements.txt
3. Run: python -m streamlit run app.py

The sidebar includes a Light mode / Dark mode switch. The welcome page has visible buttons to create an account or sign in.

Important: This is an educational demo, not real banking software. It stores data locally in data.json and does not securely hash PINs. Do not use real personal or financial information.
